# 1000 from Nepal: posting board

Daily posting board for the Colosseum Crypto World's Fair Hackathon registration push, 13 to 26 Sep 2026.

Setup once:
1. Settings, Pages, Source: Deploy from a branch, Branch: main, folder: / (root).
2. Settings, Actions, General, Workflow permissions: Read and write.
3. Actions tab, "Update Nepal registrations", Run workflow. It then runs every two hours on its own.
